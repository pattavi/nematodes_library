# nematodes_library — ห้องสมุดไส้เดือนฝอย (Nematode Library)

เว็บเก็บรูปและข้อมูลไส้เดือนฝอยระดับ **สกุล → ชนิด (genus → species)** แสดงรายละเอียดเมื่อคลิก มี 2 ภาษา (ไทย/อังกฤษ)
อ้างอิงรูปแบบจาก [NemaPlex – Nematode Genera A to B](http://nemaplex.ucdavis.edu/IndexFiles/atob.html)

> **ข้อมูลตัวอย่าง:** 14 สกุล 24 ชนิด และจุดพิกัด 34 จุดที่มากับ `npm run seed` เป็นข้อมูลที่เขียนขึ้นเพื่อทดสอบระบบ
> ชื่อชนิดเป็นชื่อจริงทางอนุกรมวิธาน แต่คำอธิบายเป็นสรุปสั้นๆ ที่เขียนเอง และ
> **พิกัดเป็นค่าสมมติ ไม่ใช่ผลการสำรวจจริง** (ในระบบติดป้าย "ข้อมูลตัวอย่าง"/`sample data`)
> ก่อนใช้งานจริงให้ใส่ข้อมูลของคุณเอง รัน `npm run seed` ซ้ำจะแทนที่เฉพาะข้อมูลตัวอย่าง ข้อมูลที่คุณเพิ่มเองไม่ถูกแตะ

## โครงสร้างข้อมูล

```
สกุล (genus)  ── ชื่อสกุล, วงศ์, กลุ่มอาหาร, ค่า c-p, หมายเหตุ ไทย/อังกฤษ
  └─ ชนิด (species) ── ชื่อชนิด (epithet), ผู้ตั้งชื่อ/ปี (authority), รหัสภายใน, หมายเหตุ ไทย/อังกฤษ
       ├─ รูปภาพ (images)   พร้อมคำบรรยาย ไทย/อังกฤษ และที่มาภาพ
       └─ จุดพิกัด (locations)  lat, lng, จังหวัด, วันที่เก็บ, หมายเหตุ
```

- **รูปและพิกัดผูกกับชนิด** ส่วนวงศ์ กลุ่มอาหาร และค่า c-p เก็บที่ระดับสกุล
- ตัวอย่างที่ระบุได้แค่ระดับสกุล ให้ใช้ชนิดชื่อ **`sp.`** (เช่น `Rhabditis sp.`)
- ชื่อชนิดซ้ำกันได้ถ้าอยู่คนละสกุล แต่ห้ามซ้ำในสกุลเดียวกัน (ไม่สนตัวพิมพ์เล็ก/ใหญ่)
- ชื่อวิทยาศาสตร์ใช้ร่วมกันทั้งสองภาษา

## ฟีเจอร์

- **หน้าแรก:** การ์ดสกุล (พร้อมจำนวนชนิด/รูป/จุด และรูปย่อ), ค้นหา (เจอทั้งชื่อสกุล ชื่อชนิด เช่น `incognita` หรือ `Meloidogyne incognita`
  วงศ์ และหมายเหตุ), กรองตามกลุ่มอาหาร, แถบตัวอักษร A–Z, เรียง A→Z / Z→A, ปุ่มล้างตัวกรอง, สลับไทย/EN
  สถานะการกรองเก็บใน URL (แชร์ลิงก์ได้)
- **หน้าสกุล** (`/#G12`): ข้อมูลสกุล, รายการชนิดในสกุล (กดเพื่อเข้าชนิด), แผนที่ย่อรวมทุกชนิด
- **หน้าชนิด** (`/#S34`): slideshow รูป, ผู้ตั้งชื่อ, ข้อมูลสกุล, หมายเหตุ, ชนิดอื่นในสกุลเดียวกัน, จุดที่พบ + แผนที่ย่อ
- **มุมมองแผนที่:** จุดบนแผนที่ประเทศไทย **แยกสีตามชนิด** รายการด้านข้างจัดกลุ่มชนิดภายใต้สกุล
  คลิกสกุลหรือชนิดเพื่อดูเฉพาะที่เลือก (มีป้ายจังหวัด) คลิกจุดเพื่อเปิดหน้าชนิด และกรองตามจังหวัดได้
  (ตัวกรองจังหวัดมีเฉพาะในมุมมองแผนที่ และนับในปุ่มล้างตัวกรองเฉพาะตอนอยู่ในแผนที่) สีมี 12 สี จึงซ้ำกันได้เมื่อมีมากกว่า 12 ชนิด
- **ผู้ดูแล (ล็อกอินด้วยรหัสผ่าน):** เพิ่ม/แก้ไข/ลบสกุล, เพิ่ม/แก้ไข/ลบชนิด, เพิ่ม/แก้ไข/ลบจุดพิกัด, ลบรูป
- **หน้า `/upload`:** เลือกสกุล → ชนิด (หรือเพิ่มสกุล/ชนิดใหม่ในหน้าเดียว), ลากวางรูปหลายไฟล์พร้อมคำบรรยายไทย/อังกฤษ,
  ใส่จุดพิกัด (ทศนิยม) พร้อมเลือกจังหวัด และเลือกตำแหน่งบนแผนที่ได้ — เปิดตรงๆ ได้ด้วย `/upload?species=ID` หรือ `/upload?genus=ID`
- **Export Excel:** ทั้งหมด / เฉพาะที่กรองอยู่ / รายสกุล / รายชนิด เลือกฝังรูปย่อได้
  ไฟล์ทั้งหมดมีชีต `Genera`, `Species`, `Images`, `Locations`

ผู้เข้าชมทั่วไป **ดูและ Export ได้** แต่แก้ข้อมูล/อัปโหลดไม่ได้ (เซิร์ฟเวอร์ตอบ 401 ทุกคำสั่งเขียนที่ไม่มี session)

## ติดตั้งและรัน

ต้องมี Node.js 22 ขึ้นไป (ตามที่ better-sqlite3 กำหนด ทดสอบกับ Node 24)

```bash
npm install
cp .env.example .env      # Windows (cmd): copy .env.example .env  แล้วแก้ค่าใน .env (ดูหัวข้อถัดไป)
npm run seed              # (ไม่บังคับ) ใส่ข้อมูลตัวอย่าง
npm start                 # เปิดที่ http://localhost:3000
```

ระหว่างพัฒนาใช้ `npm run dev` (รีสตาร์ตอัตโนมัติเมื่อแก้ไฟล์ใน `src/`)
ถ้าพอร์ต 3000 ถูกใช้อยู่ ให้ตั้ง `PORT` ใน `.env`

## ตั้งค่า (`.env`)

| ตัวแปร | ความหมาย |
|---|---|
| `ADMIN_PASSWORD` | รหัสผ่านผู้ดูแล **ถ้าเว้นว่าง = ปิดการล็อกอิน** ทุกคนดูได้อย่างเดียว และหน้าเว็บแจ้งว่า "ยังไม่ได้ตั้งรหัสผู้ดูแล" |
| `SESSION_IDLE_MIN` | นาทีที่ไม่ใช้งานแล้ว session หมดอายุ (ค่าเริ่มต้น 30) |
| `COOKIE_SECURE` | ตั้งเป็น `1` เมื่อเว็บใช้ HTTPS |
| `TRUST_PROXY` | ตั้งเป็น `1` เมื่ออยู่หลัง reverse proxy (เพื่อให้ระบบหน่วงรหัสผิดเห็น IP จริง) |
| `PORT`, `DB_PATH`, `UPLOAD_DIR` | พอร์ต / ที่เก็บฐานข้อมูล / ที่เก็บรูป (ค่าเริ่มต้น `./data/nematodes.db`, `./uploads`) |

- ตั้งรหัสผ่านที่เดาไม่ง่าย แล้วเก็บไว้ใน `.env` เท่านั้น (ไฟล์นี้อยู่ใน `.gitignore` ห้าม commit)
- รหัสผ่านถูกแฮชในหน่วยความจำตอนเริ่มเซิร์ฟเวอร์ ใส่ผิด 5 ครั้งจะถูกล็อก 1 นาที
- session เก็บในหน่วยความจำ **รีสตาร์ตเซิร์ฟเวอร์แล้วต้องล็อกอินใหม่**

## ข้อมูลและการสำรองข้อมูล

ข้อมูลทั้งหมดอยู่ในสองที่: ฐานข้อมูล SQLite `data/nematodes.db` และไฟล์รูปใน `uploads/` (รวม `uploads/thumbs/`)
สำรองโดยหยุดเซิร์ฟเวอร์แล้วคัดลอกทั้งสองที่ (หรือ export Excel เก็บไว้อีกชั้น — แต่ Excel ไม่มีไฟล์รูปต้นฉบับ)

### อัปเกรดจากเวอร์ชันระดับสกุล

ถ้ามีฐานข้อมูลเดิมที่ผูกรูป/พิกัดกับสกุลโดยตรง เซิร์ฟเวอร์จะย้ายให้อัตโนมัติตอนเริ่มทำงานครั้งแรก:
ทุกสกุลที่มีรูปหรือพิกัดจะได้ชนิด `sp.` และรูป/พิกัดเดิมย้ายไปอยู่ใต้ชนิดนั้น (ไม่ลบข้อมูล และยกเลิกการย้ายทั้งหมดถ้าจำนวนแถวไม่ตรง)
**ควรคัดลอก `data/nematodes.db` เก็บไว้ก่อนอัปเกรด** แล้วค่อยย้ายรูปไปชนิดที่ถูกต้องผ่านหน้าเว็บ

## กฎของข้อมูลที่ระบบบังคับ

- ชื่อสกุลห้ามว่างและห้ามซ้ำ ชื่อชนิดห้ามว่างและห้ามซ้ำในสกุลเดียวกัน
  ชื่อชนิดใช้ได้เฉพาะตัวอักษร ตัวเลข เว้นวรรค และ `. ( ) -` (กันอักขระแปลกปลอม)
- รูป: JPG/PNG/WebP ไม่เกิน 10 MB ต่อไฟล์ **ตรวจชนิดจากเนื้อไฟล์จริง** ไม่ใช่จากนามสกุล
- พิกัด: ทศนิยมองศาเท่านั้น (ไม่รองรับ องศา-ลิปดา) ต้องอยู่ในกรอบประเทศไทย (lat 5.5–20.5, lng 97.3–105.7)
  และ **ทุกจุดต้องเลือกจังหวัด** จาก 77 จังหวัด
- ลบสกุล = ลบทุกชนิด รูป และพิกัดของสกุลนั้น (รวมไฟล์รูป) ลบชนิด = ลบรูปและพิกัดของชนิดนั้น

## API (ย่อ)

| Method + path | สิทธิ์ | หมายเหตุ |
|---|---|---|
| `GET /api/genera?q=&feeding=&letter=&sort=asc\|desc` | ทุกคน | รายการสกุล (`q` ค้นชื่อสกุล/ชนิด/วงศ์/หมายเหตุ) |
| `GET /api/genera/:id` | ทุกคน | สกุล + รายการชนิด + จุดพิกัดรวม |
| `GET /api/species/:id` | ทุกคน | ชนิด + ข้อมูลสกุล + รูป + จุดพิกัด + ชนิดอื่นในสกุล |
| `GET /api/locations?...&province=` · `GET /api/locations/provinces` | ทุกคน | จุดสำหรับแผนที่ (ระดับชนิด) / จังหวัดที่มีข้อมูล |
| `GET /api/export.xlsx?scope=all\|view&embed=1` · `GET /api/genera/:id/export.xlsx` · `GET /api/species/:id/export.xlsx` | ทุกคน | Export Excel |
| `POST /api/login` · `POST /api/logout` · `GET /api/session` | — | ล็อกอิน/ออก/ตรวจสถานะ |
| `POST/PUT/DELETE /api/genera[/:id]` | ผู้ดูแล | จัดการสกุล |
| `POST /api/genera/:id/species` · `PUT/DELETE /api/species/:id` | ผู้ดูแล | จัดการชนิด |
| `POST /api/species/:id/images` (multipart) · `PUT/DELETE /api/images/:id` | ผู้ดูแล | จัดการรูป |
| `POST /api/species/:id/locations` · `PUT/DELETE /api/locations/:id` | ผู้ดูแล | จัดการจุดพิกัด |

## โครงสร้างโปรเจกต์

```
src/server.js     เซิร์ฟเวอร์ Express + API
src/auth.js       ล็อกอิน, session, ป้องกันคำสั่งเขียน, หน่วงรหัสผิด
src/db.js         สคีมา SQLite (better-sqlite3) + การย้ายข้อมูลจากเวอร์ชันระดับสกุล
src/seed.js       ข้อมูลตัวอย่าง (แทนที่เฉพาะแถวที่ติดป้ายตัวอย่าง)
src/provinces.js  77 จังหวัด (ชื่อ EN เป็นคีย์ + ชื่อไทย)
src/export.js     สร้างไฟล์ Excel (exceljs)
public/           หน้าเว็บ: index.html, upload.html, app.js, upload.js, i18n.js, style.css
```

## ข้อจำกัดที่ควรรู้

- **แผนที่ต้องใช้อินเทอร์เน็ต** (Leaflet จาก cdnjs และแผ่นแผนที่จาก OpenStreetMap) ออฟไลน์จะเห็นข้อความแจ้งแทนแผนที่
- **ไม่ได้ตรวจว่าพิกัดอยู่ในจังหวัดที่เลือกจริง** ตรวจแค่อยู่ในกรอบประเทศไทยและต้องเลือกจังหวัด
  (การตรวจละเอียดต้องใช้ข้อมูลขอบเขตจังหวัดเพิ่ม)
- มีผู้ดูแลรหัสเดียว (ไม่มีบัญชีผู้ใช้หลายคน)
- ระดับข้อมูลสูงสุดคือ **ชนิด** ยังไม่มีชนิดย่อย (subspecies) หรือชื่อพ้อง (synonym)
  และกลุ่มอาหาร/ค่า c-p เก็บที่ระดับสกุล ไม่แยกรายชนิด
- Export ฝังรูปย่อได้สูงสุด 200 รูปต่อไฟล์ แนะนำให้เปิดไฟล์ใน Excel จริงเพื่อตรวจฟอนต์ไทยและรูปที่ฝัง
- ทดสอบอัตโนมัติยังไม่มีในโปรเจกต์ (ตรวจด้วย curl สคริปต์ชั่วคราว และเบราว์เซอร์ระหว่างพัฒนา)

## ลิขสิทธิ์

ข้อความและรูปของ NemaPlex เป็นของเจ้าของเดิม **อย่าคัดลอกรูปหรือข้อความจากเว็บนั้นมาใช้โดยไม่ได้รับอนุญาต**
ใช้รูปที่คุณถ่ายเองหรือได้รับอนุญาต และใส่ที่มาในช่อง "ที่มาภาพ" ตอนอัปโหลด
